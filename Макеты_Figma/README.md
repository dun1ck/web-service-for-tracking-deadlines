# Векторные макеты интерфейсов для Figma

Набор минималистичных векторных экранов (`.svg`) веб-сервиса учёта заданий и дедлайнов студенческой группы, спроектированных в полном соответствии с утверждённым Техническим заданием (ТЗ).

---

## 🚀 Как открыть и редактировать в Figma

1. Откройте **Figma** (в браузере [figma.com](https://figma.com) или десктопное приложение).
2. Создайте новый пустой файл проекта (кнопка **+ Design file**).
3. **Просто перетащите (Drag & Drop)** файлы `.svg` из папки `Макеты_Figma/` на холст Figma:
   * Figma автоматически преобразует каждый файл в отдельный **Frame 1440×900 px**;
   * Все элементы разложатся на аккуратные именованные слои (`Sidebar`, `Header`, `Cards`, `Badges`, `Buttons`);
   * Все надписи превратятся в **редактируемый текст** (шрифт Inter / System UI);
   * Вы можете сразу менять цвета, переставлять блоки, добавлять связи прототипа в режиме **Prototype** и делать скриншоты для презентаций.

## 🎨 Дизайн-система (Минимализм / Clean SaaS)

* **Основной фон (Base Surface):** `#FAFAFA`
* **Фон карточек и сайдбара:** `#FFFFFF` с тонкой границей `stroke="#E5E7EB"` (1px)
* **Основной текст и контрастные кнопки:** `#18181B` (Zinc-900)
* **Второстепенный текст и подписи:** `#71717A` (Zinc-500)
* **Статус «Зачтено»:** аккуратный бейдж `#F0FDF4` с зелёной точкой `●` (`#16A34A`)
* **Статус «На проверке»:** нейтрально-янтарный бейдж `#FFFBEB` с точкой `●` (`#D97706`)
* **Статус «В процессе»:** нейтрально-серый бейдж `#F4F4F5` с точкой `●` (`#71717A`)
* **Срочные дедлайны и долги:** мягкий розовый бейдж `#FEF2F2` с точкой `●` (`#DC2626`)
* **Типографика:** `Inter`, системный `sans-serif` (без лишнего декора, акцент на чёткость структуры данных).
