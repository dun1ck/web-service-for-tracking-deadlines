# Векторные макеты интерфейсов для Figma

Набор векторных экранов (`.svg`) веб-сервиса учёта заданий и дедлайнов студенческой группы, спроектированных в полном соответствии с утверждённым Техническим заданием (ТЗ).

---

## 🚀 Как открыть и редактировать в Figma

1. Откройте **Figma** (в браузере [figma.com](https://figma.com) или десктопное приложение).
2. Создайте новый пустой файл проекта (кнопка **+ Design file**).
3. **Просто перетащите (Drag & Drop)** файлы `.svg` из папки `Макеты_Figma/` на холст Figma:
   * Figma автоматически преобразует каждый файл в отдельный **Frame 1440×900 px**;
   * Все элементы разложатся на аккуратные именованные слои (`Sidebar`, `Header`, `Cards`, `Badges`, `Buttons`);
   * Все надписи превратятся в **редактируемый текст** (шрифт Inter / System UI);
   * Вы можете сразу менять цвета, переставлять блоки, добавлять связи прототипа в режиме **Prototype** и делать скриншоты для презентаций.
